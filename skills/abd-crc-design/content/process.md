# Process

## Action Flow

### 1. clarify

Gather context for technical design - understand architecture patterns and implementation constraints

### 2. strategy

Make strategic decisions about design patterns, object responsibilities, and dependency management

### 3. build

design: refine CRC cards with OOP design patterns and detailed responsibilities Apply encapsulation, delegation, and dependency injection patterns to CRC cards Define clear object responsibilities and collaborations on each CRC card Preserve module field from domain phase, update only if class location changed Update story-graph.json domain_concepts with detailed design patterns and object interactions

### 4. validate

design: validate OOP design against design principles Ensure proper encapsulation, delegation, and dependency management Verify object responsibilities follow SOLID principles Verify module field preserved from domain phase and matches current source location

### 5. render

design: render design model documents and class diagrams

### 6. rules

Display design rules for this behavior as AI context
