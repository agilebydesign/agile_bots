## use-verb-noun-format-for-story-elements

Use verb-noun format for scenarios and acceptance criteria. Example: 'User submits form' (verb-noun)
not 'Form submission' (noun-only).

**DO**

Use verb-noun format with base verb forms. Example: 'User submits order'
'System validates payment'
'Select item from list'

Use verb-noun format for scenario sentences

```
User submits form
```

```
System processes request
```

```
Customer places order
```

```
System validates payment
```

Use verb-noun format for acceptance criteria

```
User can view order history
```

```
System displays confirmation message
```

```
Customer receives email notification
```

Use base verb forms (infinitive/imperative)
not third-person singular

```
Select item from list
```

```
Display confirmation
```

```
Add item to cart
```

```
Remove item from cart
```

**DO NOT**

Don't use noun-only
gerund
or third-person singular verb forms. Example: 'Form submission' (noun-only)
'Submitting form' (gerund)
'Selects item' (third-person)

Don't use noun-only or capability-based names for scenarios

```
Order submission
```

```
Payment processing
```

```
Form validation
```

Don't use gerund forms

```
Submitting order
```

```
Processing payment
```

```
Validating form
```

Don't use third-person singular verb forms

```
Selects item
```

```
Displays confirmation
```

```
Adds to cart
```

```
Removes from cart
```
